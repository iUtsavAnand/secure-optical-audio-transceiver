# Secure Optical Audio Transceiver (Laser Communications)

An analog, connectionless tactical communication system utilizing laser modulation to establish low-probability of intercept/detection (LPI/LPD) audio links immune to radio frequency (RF) jamming.

## Repository Overview
* **/src**: Contains hardware validation scripts and real-time waveform monitoring firmware.
* **/hardware**: Contains analog circuit designs, BJT driver schematics, and Transimpedance Amplifier layouts.
* **/docs**: Contains system block diagrams, performance metrics, and validation logs.
